## C03 历史告警与确认链

`config/scenarios/S1.json` 是固定、可读取的教学输入，`source_type=SIMULATED`、`scope=facility_baseline_input`。日期固定为 2026-10-29，`as_of=09:10:00+08:00`；这里的“当前”只相对于这一快照时间，不是计算机此刻或真实设备在线监测。

本输入声明独立 `inspection_round_id=BB02-S1-FACILITY-BASELINE-20261029` 和同日 09:00–09:45 窗口；包含 8 条当前设施观察、8 条现场记录、1 条历史告警、1 次完成复核与 4 条关联证据。

| 时间（UTC+08:00） | 数据 | 可核对内容 |
|---|---|---|
| 08:55:00 | S1-HISTORY-C03-NETWORK | ap-2f 的短时网络告警，业务 condition=WARNING；保留历史 |
| 09:03:00 | S1-INSPECTION-C03 | P1 的模拟现场记录，method=ON_SITE，属于本教学轮次 |
| 09:08:00 | S1-CURRENT-C03 | 后续远程观察可取得；本输入选择 condition=NORMAL |
| 09:09:00 | S1-EVIDENCE-CONFIRMATION | 历史告警发生事实已确认，结合远程与现场依据排除当前异常 |
| 09:09:01 | S1-REVIEW-C03 完成 | 关联确认凭据已形成；历史告警不被删除 |

`evidence.status=ok` 只表示证据取得成功；业务 condition、result、conclusion 均单独保存。确认结论通过 `basis_evidence_ids` 引用历史、当前与现场三类证据，再由 `observation_id`／`inspection_id` 回到原始记录，现场及当前确认依据通过 `review_id` 关联复核请求。

案例书没有要求 C03 必须恢复 NORMAL。本输入选择“后续正常且排除当前异常”作为明确的教学假设，**不能从查询成功推导正常**。确认仍异常但确认任务完成也是合法业务分支，既有接口回归已覆盖该分支。不能将“有告警不必然失败”扩写成“任何告警都不影响任务”。

`backend/baseline.py` 拒绝断开的关联、错用其他记录、跨轮次/窗口外现场记录、未来观察、不可取得却声称确认的证据，以及确认发生后才取得的依据。当前同步教学输入还要求确认凭据留存后才结束复核；该约束不作为未来离线同步的通用入库时间规则。

## 读取与复现

使用已有项目环境，不新增依赖。PowerShell 7 中执行：

```powershell
Set-Location -LiteralPath 'D:\校园设施巡检与复核'
$env:PYTHONDONTWRITEBYTECODE = '1'
.\.venv\Scripts\python.exe -B -c "from backend.baseline import load_s1; s = load_s1(); print(s['scenario_id'], s['scope'], s['as_of'])"
.\.venv\Scripts\python.exe -B -m pytest -q -p no:cacheprovider tests/test_facility_baseline.py tests/test_api.py
& 'D:\claude\node.exe' --test tests/frontend.test.mjs
```

测试只使用项目 `.runtime` 内隔离 SQLite 与上传目录。最后一项 Node 路径为本机已有工具位置；其他电脑使用其既有 Node。复现不会给真实数据库补入假记录，也不会刷新旧记录时间。

若要通过 HTTP 查看，按项目 README 用 `Start.ps1` 启动或重启服务，再执行：

```powershell
Invoke-RestMethod 'http://127.0.0.1:8000/api/facilities'
Invoke-RestMethod 'http://127.0.0.1:8000/api/scenarios/S1' | ConvertTo-Json -Depth 12
```

| 接口 | 返回语义 |
|---|---|
| GET /api/facilities | 配置中的 8 个设施及稳定映射 |
| GET /api/scenarios/S1 | 已校验的固定教学输入，不是 run 结果 |
| GET /api/scenarios/S2 等尚未实现值 | 404，不虚构其他场景 |
| 既有 dashboard / coverage / points / zones | 配置驱动的既有工作台数据 |

基线没有自动导入按钮和导入写接口。现场提交仍是原有真实保存流程；测试中将固定教学事实回放到隔离 SQLite，验证保存、查询及重启保留。
