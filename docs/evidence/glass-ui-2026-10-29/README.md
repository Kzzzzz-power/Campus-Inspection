# 2026-10-29 玻璃界面接入与验收

本轮将用户确认的玻璃效果预览接入正式原生前端；左上角及浏览器标题使用“校园设施巡检与复核”。工作根为 `D:\校园设施巡检与复核`。保留既有接口与业务语义，未推进后续案例开发、创建 Git 提交或更改原始资料目录。

## 实际修改

- `frontend/glass.css`：浅蓝青色玻璃层次、折角细线、概览底部光线、选择浮层与手机紧凑间距。卡片和概览不使用背景模糊；浮层局部模糊，窄屏侧栏关闭模糊。
- `frontend/filter-pickers.js`：增强原生筛选控件，按实际数据展示楼栋／楼层、点位数量；可搜索、选整栋或单层，并同步原有左导航、必检和状态筛选。没有新增不存在的房间数据。
- `frontend/index.html`、`frontend/app.js`、`frontend/motion.js`：完整中文标题、逐字翻转、玻璃装饰与浮层动效策略。下拉打开时暂停背景与拖尾；关闭、隐藏页面、离页与 BFCache 恢复均有处理。装饰不拦截点击。
- 选择浮层支持方向键、Home/End、Enter、Esc、Tab、焦点返回、外部点击关闭及短视口滚动。保留原生 select 作为值和 change 事件来源，增强销毁后恢复原控件。
- 现有详情、现场记录、实际照片、复核、覆盖运行与历史继续走真实接口；用户输入仍用文本渲染。

## 来源、复现与限制

本轮实际使用 `impeccable` 和 `animation-performance`，并按 `verification-before-completion` 核实结果。玻璃外观来自用户确认的独立预览；视频仅作色彩和线框动效参考。新增 CSS、SVG 和 JavaScript 为本项目实现，没有安装 React、GSAP 或 React Bits，也未复制 Pro 组件源码。

正式页面：http://127.0.0.1:8000/ 。本机使用现有 PowerShell 7 运行 `Start.ps1`；尝试 Windows PowerShell 5 时，既有脚本出现中文编码解析错误，切换到 PowerShell 7 后启动成功。本轮未改启动脚本。

新增浏览器检查：在新根启动独立测试 API 与 Chrome 调试实例后，设置 `INSPECTGO_TEST_URL` 和 `INSPECTGO_CDP_URL`，运行 `node tests/glass-browser.cjs`。本次分别为 `http://127.0.0.1:8016/` 和 `http://127.0.0.1:9346`。不得把任何写入回归指向正式数据库。输出位于 `.runtime/glass-implementation-2026-10-29/results`；原业务回归的隔离运行脚本保留在同目录。

本次实际浏览器为 Chrome；没有实测 Safari、Firefox、屏幕阅读器或真实手机 GPU／软键盘，未测量帧率。浮层的背景模糊有绘制成本，移动端减少大面积模糊；减少动态效果模式仍可完成全部操作。没有新增后端接口，也没有接入 MQTT、多人权限、离线同步或完整 T1—T5。
