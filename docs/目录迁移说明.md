## 迁移内容与保留方式

- backend、frontend、tests、Start.ps1、依赖清单、README、docs 与既有 Git 元数据属于项目整体，不因重建环境而遗漏源码。
- 数据库 backend/inspectgo.db 与 backend/uploads 照片按实际存在内容成套迁移。数据库内照片记录采用文件名，迁移不补造图片或修改记录时间。
- docs/evidence/B0 及 .runtime/ui-check 中已有截图、JSON 和其他历史产物随工作副本迁入。截图是界面与测试证据，不是实际设施现场照片。
- 旧 .venv 含绝对路径，需在新根基于已有 Python 3.11 重建，并按 requirements-lock.txt 安装；不能仅复制目录就判定环境已可用。

- .gitignore 排除 .venv、.runtime、数据库及日志、backend/uploads、密钥和缓存。这些文件不提交，并不意味着本地迁移时可以遗漏真实数据。源码、测试与必要文档仍应完整进入 Git。
