## 调参（改完不满意时先动这三个）

| 感受 | 调整 |
| --- | --- |
| 太亮、太花 | `--glow` 的 alpha 从 `0.18` 降到 `0.10`；网格线 alpha 从 `0.05` 降到 `0.03`；`body::after` 的 `opacity` 从 `0.85` 降到 `0.55` |
| 太暗、主题色不明显 | `--ground` 从 `#08161f` 提到 `#0b1d28`；底部辉光 alpha 从 `0.14` 提到 `0.20` |
| 玻璃太透、字发虚 | `--surface` 从 `0.78` 提到 `0.86`；卡片渐变两端各加 `0.04` 不透明度 |

## 为什么这样定

- **冷青而不是紫色**：巡检/设备/夜间值守的语义是"信号、仪表、可读"，冷青配琥珀告警最像仪表盘；紫色霓虹会把工作台拉成营销页。
- **透明只做 20%**：这是要读状态和填表单的界面，不是展示页。玻璃感来自"层次 + 发丝边 + 内高光"，不是把字放在半透明底上。
- **不给抽屉加模糊**：520px 面板滑动时对整页做 backdrop-filter，代价是每一帧重新采样背景，低端机最容易掉帧；用近不透明渐变即可。
- **不做循环光效**：工作台每天看几十次，持续动画会变成干扰，也和现有的 `prefers-reduced-motion` 策略冲突。
